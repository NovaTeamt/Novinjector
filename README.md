# Novinjector

## Общие сведения

**Novinjector** — это библиотека и инструмент командной строки для внедрения динамически загружаемых библиотек (DLL) в адресное пространство целевых процессов в операционной системе Windows. Реализация выполнена на платформе **.NET 10** с использованием системных вызовов `ntdll.dll` и `kernel32.dll`.

Продукт предназначен для использования в сценариях отладки, инструментирования и исследовательских задачах.

---

## Системные требования

| Компонент | Минимальная версия |
|-----------|--------------------|
| Операционная система | Windows 10 x64 / Windows 11 |
| Платформа выполнения | .NET 10 Runtime или SDK |
| Архитектура целевого процесса | x64 (поддержка x86 планируется) |
| Права доступа | Зависят от целевого процесса (обычно `PROCESS_ALL_ACCESS`) |

---

## Поддерживаемые методы инъекции

| Метод | Системный вызов | Механизм | Требования |
|-------|----------------|----------|-------------|
| `LoadLibrary` | `CreateRemoteThread` + `LoadLibraryW` | Удалённый поток | Целевой процесс должен загружать `kernel32.dll` |
| `ManualMapping` | `NtAllocateVirtualMemory` + `NtWriteVirtualMemory` + ручная обработка релокаций и импортов | Прямое копирование PE | Требуется реализация загрузчика в целевом процессе |
| `APC` | `QueueUserAPC` | Асинхронный вызов процедуры | Целевой поток должен находиться в состоянии `alertable` |
| `ThreadHijacking` | `SuspendThread` + `GetThreadContext` + `SetThreadContext` | Внедрение через приостановленный поток | Высокий риск нестабильности |

## Совместимость с системами защиты

> **Внимание:** Указанные данные основаны на анализе публичных источников и поведенческих тестах. Фактические результаты зависят от версии защитного механизма, режима работы и политик развёртывания.

| Защитный механизм | `LoadLibrary` | `ManualMapping` | `APC` | `ThreadHijacking` | Примечание |
|-------------------|---------------|-----------------|-------|-------------------|-------------|
| Windows Defender (последняя версия) | Обнаруживается | Частично | Обнаруживается | Обнаруживается | — при наличии сигнатуры |
| Microsoft Defender for Endpoint (EDR) | Обнаруживается | Обнаруживается | Обнаруживается | Обнаруживается | Поведенческие правила |
| BattlEye | Блокируется | Блокируется | Блокируется | Блокируется | Закрытые процессы |
| EasyAntiCheat (EAC) | Блокируется | Обнаруживается | Блокируется | Блокируется | Контроль целостности памяти |
| Vanguard (Riot Games) | Блокируется | Блокируется | Блокируется | Блокируется | Драйвер на уровне ядра |
| Xigncode3 | Обнаруживается | Блокируется | Обнаруживается | Блокируется | Контроль системных вызовов |
| nProtect GameGuard | Блокируется | Блокируется | Обнаруживается | Блокируется | — |
| Denuvo Anti-Tamper | Не применяется | Не применяется | Не применяется | Не применяется | Защищает конкретное приложение, а не систему |

**Легенда:**
- *Блокируется* — немедленное завершение целевого процесса или отклонение операции.
- *Обнаруживается* — фиксация события в логах безопасности, возможна задержанная реакция.
- *Частично* — зависит от конкретной конфигурации.
